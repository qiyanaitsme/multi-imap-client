ПРЕВРАЩЕНИЕ ПРОЕКТА В .EXE
============================
Проект: Multi IMAP Client (Electron)
Все команды выполняются в папке проекта:
  cd "C:\Users\qiyana\Desktop\IMAP CLIENT\multi-imap-client"

ШАГ 1. Установить зависимости (один раз / после клонирования)
-------------------------------------------------------------
    npm install

Что делает: скачивает все пакеты в node_modules (включая сам Electron).
Повторять не нужно, пока package.json / package-lock.json не менялись.
Если вылезают странные ошибки сборки — удалите node_modules и повторите.


ШАГ 2. Собрать один portable .exe
----------------------------------
    npm run package

Что делает (внутри две команды):
  1) electron-vite build  — компилирует исходники (src/, electron/) в out/
  2) electron-builder     — упаковывает всё в готовые файлы в dist\

Результат в папке dist\:
  - Multi IMAP Client 1.0.0.exe      <- ОДИН готовый portable-exe (запускается
                                        двойным кликом, без установки)
  - multi-imap-client-1.0.0-setup.exe<- установщик (ставит в систему, создаёт
                                        ярлыки на рабочем столе и в меню Пуск)
  - win-unpacked\                    <- распакованная версия для быстрой проверки


ШАГ 3 (опционально). Только скомпилировать без упаковки
--------------------------------------------------------
    npm run build

Что делает: только шаг 1 из сборки (src/ -> out\). Готового exe НЕ создаёт,
это промежуточный результат. Для запуска в dev-режиме используйте npm run dev.


ПОДСКАЗКИ
---------
* Windows SmartScreen при первом запуске на чужом ПК может показать
  предупреждение («Windows защитила ваш компьютер») — сборка не имеет цифровой
  подписи. Жмите «Подробнее» -> «Выполнить в любом случае».

* Если при сборке ошибка «Cannot find module electron» или пустой
  node_modules\electron\dist — зависимости не доустановились:
      npm install
  и запустите npm run package заново.

* Иконка приложения берётся из resources\icon.ico автоматически.
  Хотите сменить — замените этот файл и пересоберите (npm run package).

* Версию в имени файла (Multi IMAP Client 1.0.0.exe) меняет поле "version"
  в package.json.

* node_modules, out\ и dist\ не нужно никуда заливать — они пересоздаются.
  В .gitignore это уже учтено.
